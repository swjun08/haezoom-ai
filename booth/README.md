# 해줌 AI 부스 시연 사이트

2026 서울학생 AI 개발 성과발표회 부스용 체험 사이트입니다. 관람객이 첫 화면에서 서비스를 이해하고, 단계를 따라 체험한 뒤, 설치된 확장 프로그램으로 준비된 자료를 자유롭게 정리해 봅니다. 빌드 없이 정적 파일로 동작하며 AI 분석은 확장과 같은 Worker를 사용합니다.

## 켜기
1. `시연_시작.command`를 더블클릭합니다. Chrome에서 `http://localhost:4180`이 열립니다.
   - 처음 실행할 때 macOS가 막으면: 파일을 우클릭 → 열기.
   - 직접 켜려면 터미널에서 이 폴더로 이동한 뒤 `python3 -m http.server 4180` (저장소 루트에서는 `python3 -m http.server 4180 --directory booth`)
2. Chrome 전체 화면: `⌘ + Ctrl + F`
3. 터미널 창은 닫지 말아 주세요. 닫으면 사이트도 꺼져요.

## 행사 전 확인
- **오른쪽 위 점 색깔** = AI 서버 상태 (초록 정상 · 빨강 연결 안 됨)
- **해줌 확장 프로그램**: 최신 버전 설치, 툴바에 아이콘 고정
  - 아이콘 → 연결·설정 → **해줌 버튼 표시**를 허용해야 `localhost` 화면 오른쪽 아래에 h. 버튼이 떠요.
  - 첫 분석에서 나오는 전송 동의를 미리 한 번 해 두면 관람객 흐름이 매끄러워요.
  - 관람객이 저장한 항목은 확장 프로그램 안에 쌓여요. 행사용 Chrome 프로필을 따로 쓰는 걸 추천해요.
- **5단계 PDF**: 사이트의 ‘PDF 내려받기’로 다운로드 폴더에 미리 받아 두면 관람객이 바로 고를 수 있어요.

## 흐름 (약 3분)
모든 단계가 같은 방식이에요: **팝업으로 할 일 안내 → 위쪽 검은 안내 막대 하나를 따라 하기 → 결과 팝업**.

| 단계 | 관람객이 하는 일 | AI |
|---|---|---|
| 첫 화면 | “읽어 줌 · 정리해 줌 · 알려 줌” 세 칸이 차례로 켜짐. 아무 곳이나 누르면 시작 | 예시 화면 |
| 1 찾아보기 | 25초 동안 통신문에서 챙길 문장 6개 찾기 → “나 3/6 · 해줌 6/6” 결과 팝업 | 실시간 (게임 전에 미리 분석 시작) |
| 2 맡겨보기 | 수업 공지에서 문장 드래그 → ‘해줌으로 정리’ → 확장 프로그램과 같은 결과 창에서 ‘확인하고 저장’ | 실시간 |
| 3 챙기기 | 확장 프로그램의 ‘내 할 일 · 일정’ 화면 + 알림이 오는 모습 | – |
| 4 직접 해보기 | 준비된 자료를 **설치된 확장 프로그램**으로 정리. 확장의 진행(열림·분석·저장)에 맞춰 위쪽 안내가 바뀌고, 저장하면 완료 팝업 | 확장 프로그램 |

- 4단계에서 확장이 반응하지 않으면 왼쪽 아래 ‘확장이 반응하지 않나요?’로 웹에서 바로 분석할 수 있어요.
- 텍스트 자료(단톡방·게시판·1단계 통신문)의 날짜는 **방문한 날 기준**으로 자동 계산돼서 항상 앞으로 올 날짜예요.

## 진행자 도구
- 주소 뒤에 `#1`(찾아보기) `#2`(맡겨보기) `#4`(챙기기) `#5`(직접 해보기)를 붙이면 그 단계로 바로 열려요.
- 오른쪽 위 **처음으로** = 전체 초기화 (사이트 안의 기록만 지워지고, 확장 프로그램에 저장한 건 그대로)
- 100초 동안 아무 조작이 없으면 안내 후 처음 화면으로 돌아가요.
- AI 서버는 같은 인터넷(IP)에서 **1분에 10번**까지 받아요. 몰리면 “10초 뒤 다시” 안내가 떠요.
