# 디자인 기준

사용자가 지정한 두 저장소의 실제 스타일을 참고했습니다.

- https://github.com/swjun08/ieasy-caption-extensions — 로컬 체크아웃의 samsung-extension/styles/universal-simplify.css
- https://github.com/swjun08/mallang — GitHub popup/popup.css

공통 토큰: ink #14171f / muted #6b7280 / line #e5e7eb / sub #f3f4f6 / bg #ffffff. Pretendard Variable, 검정 주 버튼, 회색 보조 버튼, 작은 상태 배지, 둥근 컨트롤, 파란 키보드 초점 표시를 계승합니다. 민트 #177a59는 보조 장식에만 사용합니다. 마스코트·로고를 복제하지 않고 해줌 워드마크를 사용합니다.

드래그 개선: 확장 아이콘으로 돌아갈 필요 없이 선택 옆 버튼, 글자 수, 자동 전송 없음 안내, Esc 닫기, 입력창 제외, 화면 가장자리 위치 보정, 사이트별 활성화/해제. 권한 허용 후 해당 사이트에서만 작동합니다. 클릭하면 분석 전 확인 화면으로 이동합니다.

문서 입력 → 결과 → 확인 → 할 일의 순서를 분리합니다. 날짜 없는 자료는 추측하지 않고 원문을 보여주며, 사용자가 날짜를 직접 지정해 확인합니다. 시각적 완료와 실제 서비스 연결 상태를 혼동하지 않도록 상단에 검토 버전 배지를 고정적으로 표시합니다.

UI 프리뷰의 모든 날짜는 샘플 데이터입니다. 화면의 미리보기 동작이 실서비스 분석·저장·알림 성공을 의미하지 않습니다.

2.1: 이편한자막 일반 사이트의 플로팅 버튼 → 페이지 도우미 패널 패턴을 참고해 오른쪽 아래 원형 h. 로고를 추가했습니다. 누르면 선택 문장 미리보기와 문서 정리·내 할 일·사용 안내가 펼쳐집니다. 사이트별 활성화 원칙과 문장 옆 드래그 칩을 함께 유지합니다. 메뉴는 Esc/바깥 클릭/닫기로 접고, 원형 버튼은 현재 페이지에서 숨길 수 있습니다. 새로고침하면 다시 표시됩니다.
