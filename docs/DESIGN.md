# 화면 설계와 검수 · 3.1.0

이편한자막·말랑의 흰 배경, 검정 주 버튼, 연회색 보조 영역, 둥근 모서리와 간결한 아이콘을 참고했습니다. 워크스페이스는 Pretendard, 페이지 내 UI는 사이트에 영향을 주지 않는 시스템 한글 글꼴을 사용합니다.

## 중심 흐름

1. 공지를 읽던 페이지에서 상단 아이콘 또는 원형 h. 버튼을 누릅니다.
2. 문장 선택·영역 캡처·PDF 중 하나로 가져옵니다.
3. 원문 확인 후 AI 분석에 동의합니다.
4. 왼쪽에서 항목을 선택하고 오른쪽에서 날짜·정리 내용·메모를 확인합니다.
5. 원하는 항목만 저장하고 현재 페이지로 돌아갑니다.
6. 일정 확인·메모 보완·완료 처리가 필요할 때 워크스페이스를 엽니다.

## 배치 기준

- 상단 아이콘은 오른쪽 위에서 내려오는 메뉴, 떠 있는 버튼은 가까운 쪽 메뉴로 구분합니다.
- 결과 목록과 선택한 항목의 내용은 분리합니다. 긴 문서 요약은 기본 접힘, 개별 항목의 행동·준비물·비용·제출 방법은 펼침입니다.
- 저장 버튼과 선택 개수는 스크롤 영역 밖 하단에 둡니다. 원문/결과 전환 시 입력한 메모를 유지합니다.
- 오늘 화면에서 큰 안내문 대신 실제 항목을 먼저 보여줍니다. 날짜가 없는 항목도 숨기지 않습니다.
- 목록에는 제목·날짜·메모 또는 정리 내용 한 줄, 상세 화면에는 정보별 라벨과 메모 입력을 배치합니다.
- 캘린더 셀 전체를 선택 영역으로 사용합니다. 우측에서 그 날짜의 항목과 추가 기능을 제공합니다.
- 완료는 즉시 되돌릴 수 있습니다. 토스트는 하단 중앙에 두어 주요 버튼과 겹치지 않게 합니다.
- 긴 데이터는 내부 스크롤, 작은 화면에서는 순서를 유지해 한 열로 전환합니다. 이미지에는 contain을 적용합니다.

## 소개와 체험 사이트

첫 화면은 긴 홍보 문구 대신 공지 선택→항목 분류를 짧게 한 번 보여줍니다. 입력 방식 탭과 다시 보기로 직접 조작할 수 있고 reduced-motion에서는 완성 상태를 바로 표시합니다. 본문은 문제→사용 방식→팀→체험 순서입니다. 팀 소개에는 실제 역할 분담을 기재했습니다.

체험은 별도 하위 페이지입니다. 본문 옆 말풍선과 확장 결과창 안의 안내를 함께 사용해 모달 뒤 안내가 가려져도 다음 행동을 알 수 있습니다. 기존 저장 데이터를 지우거나 고정 AI 결과로 성공을 연출하지 않습니다.
