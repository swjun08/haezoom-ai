## 이번에 제가 구현한 범위

수정된 UI에 맞춰 핵심 기능들이 작동하도록 AI가 들어가 있는 구글 클라우드 플레어 서버에 연결을 진행 했습니다
또한 기존 캡쳐 분석의 작동 방식인 '캡쳐 -> 로컬 ocr 로 텍스트 추출 -> ai서버에 추출된 텍스트를 기반으로 분석 요청'이던 방식을
'캡쳐 -> 캡쳐된 이미지를 AI 서버에 분석 요청'으로 바꾸어 로컬 ocr이 표로 이루어져 있는 문서를 잘 읽지 못하던 문제를 해결했습니다


| 수정한 부분 | 바꾼 이유 |
|---|---|
| 이편한자막·말랑과 맞춘 Pretendard, 흰색/회색 바탕, 검정 버튼, 둥근 카드 | 팀 서비스의 일관성을 유지하고 화면을 간결하게 만들기 위해 |

| 버튼 드래그 이동, 화면 밖 이동 제한, Alt+방향키 이동 | 본문이나 사이트 버튼을 가리지 않도록 |
| 이동한 버튼의 위/아래 여유 공간에 맞춰 열리는 메뉴 | 로고와 메뉴가 겹치던 문제 해결. 공간 부족 시 메뉴 내부 스크롤 |

| 큰 홍보 영역 축소, 한 화면의 입력·결과·주요 버튼 | 페이지 전체를 내려야 하던 어색함을 줄이고 다음 행동을 바로 보이도록 |

| 화면 영역 선택 → 미리보기 → 확인 후 가져오기 | 필요 없는 정보나 개인정보까지 실수로 가져오지 않도록 |
| 문장 드래그 옆 정리 버튼, 선택 글자 수·메뉴 안 미리보기, Esc 닫기·입력창 제외 | 선택 범위를 확인하고 작성 중인 글에 방해받지 않도록 |
| 한 번 승인하면 HTTP/HTTPS 사이트에 자동 표시하는 전체 사이트 모드 | 사이트마다 도우미를 다시 켜야 하는 번거로움 해소 |
| 로컬 PDF 화면 로고 지원 및 파일 접근 설정 안내 | 가정통신문을 브라우저 PDF 뷰어로 볼 때도 동일한 진입점을 제공하도록 |

| 샘플 5종, 날짜/내용 편집·완료·검색·필터·삭제·JSON 내보내기 화면 | 서버 연결 전에 사용자 흐름을 검토할 수 있도록 |

## 현재 상태를 꼭 구분해 주세요

- 샘플 버튼은 수작업으로 작성한 예시 결과입니다. 실제 AI 분석이나 정확도 검증 결과가 아닙니다.
- 목록은 Chrome 프로필에 저장되어 화면을 닫거나 새로고침해도 유지됩니다. 단 항목은 기기 간 동기화되지 않습니다.
- 선택 텍스트와 캡쳐 이미지는 페이지 안 확인 창에서 유지합니다. 분석 동의 시 선택 원문은 텍스트로, 캡쳐 이미지는 이미지 자체로 Worker를 거쳐 Claude에 전송합니다. PDF·이미지도 원본 파일로 전송하며 이미지 속 개인정보가 포함될 수 있습니다.
- Cloudflare Secret `ANTHROPIC_API_KEY`, 변수 `CLAUDE_MODEL`, IP당 분당 10회 제한을 사용합니다. 키 값은 확장 프로그램이나 저장소에 넣지 않습니다.
- PDF 페이지 수 확인은 로컬에서 수행하며 파일/캡쳐의 OCR은 Claude가 분석 중 함께 수행합니다. 복잡한 표·스캔 PDF·작은 글씨 등의 정확도는 실제 문서 세트로 추가 검증해야 합니다.
- 전체 사이트 자동 표시는 최초 웹사이트 접근 권한 승인이 필요합니다. 크롬 설정·웹스토어 등 제한 화면까지 지원한다는 의미는 아닙니다.
- 로컬 PDF 로고는 Chrome의 ‘파일 URL에 대한 액세스 허용’이 필요합니다. PDF 내부 텍스트 선택을 직접 읽는 기능은 미구현이며 캡쳐/업로드 경로를 사용합니다.
- 화면 캡쳐 권한이 부족하면 상단 해줌 아이콘의 ‘현재 화면 캡쳐하기’로 시작해야 합니다.

## 팀원이 이어서 해주실 일

### AI 담당

1. 완료: `run`과 `review.js`가 같은 Worker API를 호출합니다. Claude 모델은 Worker의 `CLAUDE_MODEL` 설정으로 제어합니다.
2. 완료: `summary / tasks / schedules` 응답은 `core.mjs`에서 검증·변환되며 준비물·비용·제출처·근거·검토 상태를 유지합니다.
3. 완료: 연도가 없는 날짜를 Worker에서 연도 보정하지 않고 원문으로 유지해 사용자가 확인하도록 합니다.
4. 샘플 문서 5개 이상에 대해 원문·기대값·실제 JSON·누락/오류를 기록해 주세요. 현재 고정 샘플을 AI 성공 사례로 사용하지 말아 주세요.
5. 완료: API 키는 Cloudflare Secret으로 관리하고 IP당 분당 10회 제한·입력 제한·오류 응답·타임아웃·전송 동의를 적용했습니다. 사용자 인증과 추가 악용 방지 정책은 별도 검토가 필요합니다.

### 확장 프로그램 담당

1. 선택 텍스트·PDF·캡쳐 결과를 같은 저장 모델에 저장하고, 수정·완료·삭제를 영구 보존합니다.
2. Google 로그인 및 확인 완료·유효 날짜·미완료 항목의 수동 Calendar 등록/업데이트와 중복 방지 경로를 추가했습니다.
3. 실제 Google 계정으로 OAuth 승인, 캘린더 이벤트 등록, 토큰 만료·권한 취소·실패 복구를 확인해 주세요. OAuth 클라이언트가 Chrome Extension 유형이고 확장 프로그램 ID가 일치해야 합니다.
4. 한국 시간 기준 마감 3일 전·1일 전·당일 알림과 재시작 복구를 구현해 주세요.
5. 실제 Chrome에서 전체 사이트 권한 승인·해제, PDF 파일 접근, 재시작, 캡쳐 권한 부족·취소·재시도, Claude의 PDF/표/이미지 인식과 실패 응답을 검증해 주세요.
6. 여러 환경에서 chrome extension의 ID가 변경되지 않는지 확인 해 주세요 만약 변경될 시 'manifest.json'에서 key로 ID를 고정시켜주세요 (AI담당의 추가요청)

## 개발 시작

`chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → 저장소의 `extension` 폴더 선택. 일반 사이트는 해줌 팝업에서 전체 사이트 모드를 한 번 승인합니다. 로컬 PDF는 상세 설정의 파일 URL 액세스도 켜 주세요.
