# 팀 공유 · 이번 구현 범위와 남은 작업

팀 저장소 `wodlelflt/haezoom-ai`의 `b08cc6d`를 기준으로 UI와 서비스 흐름을 확장했습니다. 현재 버전은 3.1.0입니다.

## 변경한 부분과 이유

| 변경 | 이유 |
|---|---|
| 상단 드롭다운과 드래그 가능한 원형 버튼 | 읽던 화면에서 시작하고 메뉴 위치를 예측할 수 있도록 개선 |
| 페이지 안 입력·결과·저장 연결 | 캡처 후 빈 창과 새 탭 이동 문제 해결 |
| PDF 선택 상태, 페이지 미리보기, 로딩·오류 분리 | 깨진 이미지와 멈춘 미리보기 해결 |
| 결과 목록 / 선택 항목 상세의 좌우 배치 | 긴 요약·큰 카드에 묻히던 세부 내용과 저장 버튼 개선 |
| 정리 내용·문서 요약·개인 메모 저장 | 저장 후 제목만으로 내용을 다시 추측하지 않도록 개선 |
| 오늘·목록·월간 달력 구조 재설계 | 일정 관리에 필요한 기능을 한 화면에 배치 |
| 완료 취소와 날짜 칸 전체 선택 | 실제 사용 중 실수 복구 및 작은 클릭 영역 문제 해결 |
| 자체 Chrome 알림, 로컬 저장·백업 | Google 연결 없이 기본 사용 가능 |
| Calendar 중복 방지·갱신·삭제·오류 복구 | 실제 연동을 위한 데이터/실패 처리 구현 |
| Classroom 형태의 시연 교실 | 가상 공지와 제공 PDF로 재현 가능한 시연 구성 |

## 팀원이 이어서 할 일

1. **Google 연결 최종 확인:** 3.1.0에서 확장 ID를 고정하고 OAuth 클라이언트를 설정했습니다. 연결할 팀원 계정을 Google Cloud의 테스트 사용자에 추가한 뒤, 실제 계정에서 연결→등록→수정→중복 등록→삭제→연결 해제를 확인합니다. 3.0.x에서 올릴 때는 ID가 바뀌므로 백업 후 재설치합니다.
2. **문서 정확도 측정:** 실제 동의를 받은 비식별 샘플로 복잡한 표·스캔·작은 글씨·상대 날짜를 평가합니다. 정확도와 사용 시간을 각각 측정합니다.
3. **알림 실기 검증:** Windows와 macOS에서 OS 허용/차단, 절전, Chrome 종료·재시작, 알림 클릭을 확인합니다.
4. **공개 운영 준비:** API 비용 상한과 접근 통제, 개인정보 안내, 문의 경로, 확장 배포 및 업데이트 방식을 확정합니다.
5. **최종 사용자 테스트:** 문장·캡처·PDF 각각 가져오기→날짜/내용 확인→메모→저장→완료/취소를 설명 없이 수행하는지 관찰합니다.

시연 사이트는 현재 소유자 로그인 전용입니다. 팀원은 저장소의 `demo/`를 로컬 실행할 수 있습니다. 실험용 테스트 계정 데이터와 실제 사용자 데이터를 섞지 않습니다.

검사 명령·실제/모의 범위·사진은 [README](../README.md), [QA](QA.md), [디자인](DESIGN.md)에 정리했습니다.

## 관람객 체험 사이트

소개 홈페이지, 팀 소개, 동작 미리보기 모션, 세 가지 자율 체험과 PDF 체험을 추가했습니다. 자세한 경로·진행자 준비·데이터 경계는 `demo/README.md`에 있습니다. Google Calendar 연결 없이도 분석→확인→메모→브라우저 저장을 시연할 수 있습니다. 사이트 공개 범위는 기존 소유자 전용 상태를 유지했습니다.
