## 실제 AI 확인

`verification/live-ai-2026-11-17.json`: 가상 텍스트 5종을 운영 API로 분석했습니다. 형식과 반환 결과를 기록했으며, 고정 샘플 기대값과 실제 AI 응답을 구분했습니다.

제공된 PDF 전체 8페이지를 한 번에 보내는 검사는 분석 결과를 얻지 못했습니다. 그 때문에 사용자 흐름은 **선택 페이지를 로컬 렌더링하고 한 페이지 이미지를 분석하는 방식**으로 변경했습니다. 해당 방식은 실제 분석·저장까지 통과했습니다. 저장 결과는 `verification/live-pdf-page-2026-11-17.json`에 있습니다. 표·스캔·흐릿한 글씨 전반의 정확도를 보장하는 수치는 아닙니다.

## 사용자 Chrome 관찰

- 기존 설치 경로를 유지해 버전을 갱신하고, 실제 시연 교실의 원형 메뉴·PDF 페이지 미리보기를 확인했습니다.
- PDF를 여는 동안 멈추던 원인은 숨겨진 offscreen 문서에서 PDF.js의 화면 프레임을 기다리는 렌더링이었습니다. 인쇄 렌더링 경로로 수정 후 실제 페이지가 표시됐습니다.
- 사용자가 실제 페이지에서 캡처 분석을 진행하는 상태와 결과 화면을 관찰했습니다.
- Chrome 알림 설정과 테스트 요청을 실행했으나 **OS 알림 배너의 실제 표시·클릭은 확인하지 못했습니다.**
- Google 연결 버튼 실행 시 인증 실패를 관찰했습니다. **실제 계정에서 Calendar 등록·수정·삭제가 완료됐다는 증거는 없습니다.** 현재 확장 ID와 OAuth 클라이언트, 계정 로그인·테스트 사용자 설정을 확인해야 합니다.
