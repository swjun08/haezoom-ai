선택만 해도 전송되나요?

아니요. 문장을 드래그하는 것만으로 외부 AI에 보내지 않아요. 가져온 내용을 확인하고, 실제 분석을 시작할 때 전송 동의를 확인해요.

어디로 보내나요?

실제 분석에 동의한 문서 내용은 해줌 서버를 거쳐 Claude로 전달돼요. 필요하지 않은 개인정보는 분석 전에 제외하세요.

어디에 저장하나요?

할 일·일정과 메모는 현재 Chrome 프로필의 로컬 저장소에 저장돼요. 홈페이지 예시에서 작성한 내용은 새로고침하면 초기화돼요.
