할 일과 일정 확인

제출하거나 준비해야 하는 내용은 할 일, 참석하는 행사는 일정으로 나눠요. 잘못 분류됐다면 결과의 할 일·일정 버튼으로 바꿀 수 있어요.

날짜와 원문 확인

AI가 정리한 내용은 원문과 비교해 주세요. 날짜가 모호하거나 빠졌다면 직접 입력하세요. 확실하지 않은 날짜는 직접 확인하도록 남겨요.

메모와 저장

각 항목의 내 메모에 준비 상황을 적을 수 있어요. 저장할 항목만 선택한 뒤 확인하고 저장을 누르면 상세 내용과 메모가 함께 남아요.
