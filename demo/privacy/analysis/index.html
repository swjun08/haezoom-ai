분석 요청의 흐름

1. 요청 확인

가져온 문장이나 문서 이미지를 확인합니다. 전송 안내에 동의하고 분석을 시작한 경우에만 AI 분석 요청을 보냅니다.

2. 서버 전달

Cloudflare에서 동작하는 해줌 서버가 분석 요청을 Claude에 전달합니다. AI API 키는 브라우저 코드에 넣지 않고 서버에서 사용합니다.

3. 결과 확인

AI가 할 일·일정과 날짜, 준비물 등을 반환합니다. 원문을 대조하고 내용을 수정한 뒤 필요한 항목만 저장할 수 있습니다.

소개 화면의 예시

홈페이지의 자동 재생 화면은 미리 준비한 예시 결과를 사용합니다. 이 화면에서 내용을 수정해도 실제 AI 서버로 전송하지 않습니다.
