분석에 사용하는 정보

사용자가 선택한 문장, 캡처 이미지, PDF에서 가져온 문서 내용이 분석 대상입니다. 필요하지 않은 이름이나 연락처는 보내기 전에 제외해 주세요.

외부 AI 전송

실제 분석을 요청하면 선택한 내용이 Cloudflare의 해줌 서버를 거쳐 Anthropic Claude로 전달됩니다. 외부 서비스의 처리 조건과 보관 정책은 해당 제공사의 정책을 따르며, 해줌이 외부 제공사의 무보관을 보장하는 것은 아닙니다.

로컬 저장

할 일·일정, 상세 메모와 사용자 설정은 Chrome 확장 프로그램의 로컬 저장소에 저장됩니다. 이 저장소는 브라우저 프로필별로 구분되며 별도 계정 동기화 저장소가 아닙니다.

Google Calendar

사용자가 연결을 선택하면 Google 인증을 진행합니다. 등록하는 일정의 제목, 날짜, 시간과 설명 등이 Google Calendar에 전달됩니다. 연결 해제만으로 기존 일정이 삭제되지는 않습니다.

홈페이지 예시

소개 화면의 예시는 미리 작성한 결과를 재생합니다. 예시에서 작성한 메모는 해당 화면의 메모리에만 남으며 새로고침하면 초기화됩니다.
