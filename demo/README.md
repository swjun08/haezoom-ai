# 해줌 AI 소개 및 체험 사이트

이편한자막 웹사이트의 글꼴·여백·버튼 비율을 바탕으로 해줌의 서비스 소개·팀 소개·체험을 담은 정적 사이트입니다.

## 로컬 실행

저장소 루트에서 `python3 -m http.server 4173 --directory demo`를 실행하고 `http://localhost:4173`을 엽니다. 루트 경로로 제공해야 하위 페이지·자산 링크가 동작합니다.

## 관람객 동선

홈페이지 → 직접 체험하기 → 공지 선택 → 문장 선택/화면 캡처 → AI 분석 → 항목·날짜·준비물 확인 → 메모 → 저장 → 다음 체험 또는 내 할 일 확인.

1. **신청과 참석, 따로 챙기기** `/experience/select/`: 워크숍 신청 기한과 실제 참석 일정을 구분합니다. 준비물을 확인하고 준비 상황을 메모합니다.
2. **표에 흩어진 마감일 모으기** `/experience/capture/`: Chrome 상단 해줌 버튼 → 화면 캡처. 과제 표 전체를 캡처해 세 가지 제출 기한을 대조합니다.
3. **애매한 날짜, 직접 확인하기** `/experience/date/`: 작성일·정확한 날짜가 없는 공지입니다. AI 결과를 원문과 대조하고, 모르는 날짜는 비워 두거나 확인할 내용을 메모합니다.
4. **선택 체험: PDF** `/experience/pdf/`: 원본 양식 문서 8페이지를 내려받고 해줌에서 파일·페이지를 선택합니다. 원본 문서의 날짜는 변환하지 않습니다.

가상 텍스트 공지의 날짜는 한국 시간 방문일 기준 3·6·7·9일 뒤로 설정되어 지난 일정으로 시연하지 않습니다. 홈페이지의 움직이는 제품 그림은 설명용 예시이며 실제 AI 결과가 아닙니다. 실제 체험은 설치된 확장을 이용합니다.

## 진행자 준비

- PC Chrome에 최신 해줌을 설치하고 상단 아이콘을 고정합니다. 업데이트한 뒤 체험 페이지도 새로고침합니다.
- 운영 API 연결을 확인합니다. 첫 분석에서 원문/이미지 전송 동의를 읽을 수 있도록 합니다.
- 개인 데이터와 시연 자료가 섞이지 않도록 행사에는 별도 Chrome 프로필을 권장합니다. 사이트의 ‘체험 표시 초기화’는 확장에 저장한 내용을 삭제하지 않습니다.
- Google Calendar 없이 분석·브라우저 저장을 체험할 수 있습니다. 실제 Google 연결과 OS 알림 배너 검증은 QA 문서에 분리했습니다.
- 현재 호스팅은 소유자 로그인 전용입니다. 행사 PC에서는 로그인된 상태로 사용하고, 외부 관람객에게 링크를 배포하려면 사이트 공개 범위를 별도로 설정해야 합니다.

## 안내 연결과 데이터

`meta[name=haezoom-demo]`가 있는 체험 페이지에서만 확장이 `haezoom-demo-progress`를 내보냅니다. 문자열 JSON의 `mission`, `step` 두 값만 전송합니다. 단계는 opened/analyzed/saved/closed이며, 사이트에서 확장으로 들어가는 명령은 없습니다. 웹페이지가 이벤트를 흉내 내더라도 체험 안내만 바뀌며 확장 저장·권한에는 영향이 없습니다.

원문·AI 결과·날짜·메모 등은 사이트에 전달하지 않습니다. 완료 표시는 sessionStorage에 보관하고 분석 창을 취소하면 가져오기 단계로 돌아갑니다. 사이트 자체에 AI API 키나 로그인 토큰은 없습니다.

기존 교실과 PDF 미리보기는 `/classroom/`에 유지합니다. 가상 공지이며 실제 학교 계정·댓글·제출 시스템이 아닙니다.
